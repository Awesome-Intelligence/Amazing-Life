## 🌲 先建立一个目标树

我们设计了一套 **4 层目标结构**：

```
人生目标 (Level 1)
      ↓
阶段目标 (Level 2)      ← 比如"35岁前成为技术专家"
      ↓
年度目标 (Level 3)      ← 比如"2026年技术深度提升"
      ↓
短期目标 (Level 4)      ← 比如"Q3 完成系统设计文档"
```

这不是人为制造的层级。

**这是本来就存在的结构。**

你的每一个日常行动，都属于某个短期目标；
每一个短期目标，都属于某个年度目标；
每一个年度目标，都属于某个阶段目标；
每一个阶段目标，都通向人生目标。

插件会自动计算：**当你完成一个短期目标，父目标的进度自动更新。**

你不需要手动更新进度。你只需要做事情。

---

## 📝 然后，像写日记一样工作

在 Amazing Life 里，你只需要：

```
今天完成了产品设计初稿  #目标/职业发展 #noteworthy
```

就这么简单。`#目标/职业发展` 这几个字，会：

1. **关联到对应的目标** - 系统知道你在为这个目标工作
2. **记录到目标的提及历史** - 日后可以回顾"这段时间我为这个目标做了什么"
3. **如果标记了 #noteworthy** - 自动汇总到周记/月记，成为你的阶段总结素材

你不是在"管理目标"。你只是在**记录你在做什么**。

目标会自动"看见"你在为它努力。

## 🌀 两条脉络交织

Amazing Life 有两条交织的脉络：

**纵脉：目标的层级结构**

- 人生 → 阶段 → 年度 → 短期
- 让你始终知道自己在大方向上

**横脉：时间的连续记录**

- 日记 → 周记 → 月记 → 年记
- 让你看见自己的成长轨迹

当这两条脉络交织，你会获得一种**前所未有的清晰感**：

> "我知道我在为什么努力，我知道我做到了什么，我知道我还要做什么。"

这比任何目标管理 app 的统计数据都更有价值。

## 💡 设计理念

### 工具应该隐形

我们相信：**最好的工具是不需要你刻意去用的工具**。

传统的目标管理 app 要求你：
- 打开 app
- 切换到"目标"模块
- 创建/更新目标
- 切换到"任务"模块
- 创建/更新任务
- 切换到"日记"模块
- 写今天的记录

这一路切换下来，写日记的冲动早就消失了。

Amazing Life 的思路是：**让你在做本来就在做的事情时，顺手完成目标管理。**

你本来就要写日记。在写的时候加上 `#目标/xxx`，这就是全部的操作。

### 最小阻力路径

人类天生懒惰——这不是缺点，这是进化赋予我们的节能本能。

任何需要"额外步骤"的事情，长期来看都会被放弃。

所以我们把目标管理的入口，放在了你每天必做的事情里：**写日记**。

你只管写，插件在背后默默工作。

### Markdown 是永恒的

我们选择 Markdown 文件存储数据，因为：

- **你拥有数据** - 不是某个云服务的数据库，不是某个公司的服务器。就是你自己的 .md 文件。
- **格式开放** - 50 年后还能打开。不用担心某个 app 停止运营，数据全部消失。
- **可迁移** - 今天用 Obsidian，明天用 Logseq/Tana/任意工具，数据直接迁移。

我们不想做一个"锁定用户"的插件。我们想做的是一个"随时可以离开"的工具。

因为只有随时可以离开，选择留下才是真正的自由。

## ✨ 功能亮点

### 🎯 4层目标体系

- 人生目标 → 阶段目标 → 年度目标 → 短期目标
- 自动计算聚合进度，父目标进度由子目标自动汇总

### 📝 在日记里创建和关联任务

```
## 今日记录

上午完成了产品设计初稿  #目标/职业发展 #noteworthy

- [ ] 准备晋升述职材料  #目标/职业发展
- [ ] 回复团队邮件  #任务/日常
```

**任务的创建和关联，只需一行：**

- `- [ ]` 创建待办任务（标准的 Markdown 复选框语法）
- `#目标/xxx` 把任务关联到对应目标
- `#任务/xxx` 给任务打上类型标签（如"重要"、"日常"、"学习"）
- `#noteworthy` 标记重要内容，自动汇总到周记/月记

**你不需要进入"任务管理"模块。** 任务就在你的日记里，和你的想法、感受、记录在一起。

### 📊 多种视图

- **仪表盘** - 今日待办、本周完成、目标进度一览
- **列表视图** - 表格形式查看所有目标
- **看板视图** - 按状态/层级分组，拖拽管理
- **画廊视图** - 卡片网格，直观展示
- **日历视图** - 按日期查看任务分布

### 📁 数据存储

- 所有数据以 `.md` 文件存储
- 完全掌控你的数据
- 支持 Obsidian 同步到任意设备
- 可配合 Dataview 自由查询

## 🚀 快速开始

### 1. 安装插件

在 Obsidian 社区插件市场搜索 "Amazing Life" 安装

### 2. 创建目标

1. 打开 Amazing Life 仪表盘
2. 点击 "+ 添加目标"
3. 选择层级（人生/阶段/年度/短期）
4. 填写名称和描述

### 3. 在日记中工作

```
## 今日记录

上午完成了产品设计文档初稿  #目标/职业发展 #noteworthy

- [ ] 准备晋升述职材料  #目标/职业发展
- [ ] 回复团队邮件  #任务/日常

今天的项目进度比预期快一点，希望保持这个节奏  #目标/项目A
```

### 4. 查看进度

- 打开仪表盘，查看今日待办和本周完成
- 进入目标详情，查看提及历史和进度变化
- 打开周记/月记，汇总期间的重要记录

---

## 📋 工作流示例

**每日**
```
打开日记 → 记录待办/进展 → 用标签关联 → 标记重要内容
```

**每周**
```
打开周记 → 汇总 #noteworthy → 回顾目标进度 → 调整下周计划
```

**每月/每年**
```
回顾总结 → 分析进度趋势 → 调整目标方向 → 设定新目标
```

## 🌱 为什么这能长期坚持

你可能有过这样的经历：

- 下载了一个目标管理 app，用了两周放弃了
- 买了课程，学完就忘
- 列了完美的计划，执行了三天

**为什么？**

因为这些方法都在要求你**额外做些什么**。而"额外"就意味着消耗意志力。意志力是有限的，用完就没了。

Amazing Life 的设计目标：**不需要消耗意志力的目标管理。**

你不需要"打开 app 更新进度"这个动作。
你不需要"记得今天有哪些目标要推进"这个记忆负担。
你不需要"定期同步数据"这个维护工作。

**你只需要继续写日记。**

那些目标会在日记里自然生长，在仪表盘里可视化呈现，在周记月记里自动汇总。

这不是一套新的习惯。这是在你已有的习惯上，叠加一层薄薄的框架。
