# Amazing Life

**版本**: v1.0.0  
**创建日期**: 2026-07-22  
**状态**: 规划中

---

## 项目简介

一个以**日记为核心**的生活管理插件。通过日常书写自然地管理目标和任务，特殊标记的内容自动汇总到周记、月记、年记和目标记中。

## 核心理念

**"日记驱动的工作流"** - 用户每天写日记，通过标签自然地关联目标和任务，无需切换界面或手动同步。统计和进度信息集中在独立的仪表盘展示，保持日记的纯粹性。

## 核心特性

| 特性 | 描述 |
|------|------|
| 📝 日记驱动 | 以日记为主入口，通过标签关联目标和任务 |
| 🎯 层级目标 | 4级目标结构（人生→阶段→年度→短期），自动计算进度 |
| 📊 层级记录 | 日记/周记/月记/年记/目标记五级记录体系 |
| ⭐ 标记汇总 | `#noteworthy` 标记自动汇总到上级记录 |
| 📈 仪表盘 | 可视化展示统计和进度（不污染日记） |
| 📱 多端同步 | 支持电脑端和手机端，Markdown 文件同步 |

## 快速开始

### 1. 创建目标
```
命令: Amazing Life: 新建目标
选择目标层级（人生/阶段/年度/短期）
填写目标名称和描述
```

### 2. 在日记中关联任务
```
打开今日日记
写下任务 - [ ] 完成项目文档
添加目标标签 #目标/职业发展
如需汇总，添加 #noteworthy
```

### 3. 汇总到周记
```
命令: Amazing Life: 新建周记
命令: Amazing Life: 汇总本周重点
```

## 标签系统

| 标签 | 语法 | 说明 |
|------|------|------|
| 目标关联 | `#目标/xxx` | 将任务关联到目标 |
| 任务标记 | `#任务/xxx` | 标记任务类型 |
| 重要标记 | `#noteworthy` | 标记重要内容，汇总到上级 |
