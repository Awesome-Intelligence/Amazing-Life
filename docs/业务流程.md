## 一、核心工作流

### 1.1 日记驱动工作流

```
用户打开今日日记
    ↓
写下今日任务 - [ ] 完成项目文档 #目标/职业发展 #任务/项目文档
    ↓
标记重要内容 今天突破了技术瓶颈，很有成就感 #noteworthy
    ↓
插件自动识别并更新
    ↓
仪表盘自动反映最新进度
```

**设计原则**：
- 日记保持纯净，不自动插入统计信息块
- 所有交互通过标签完成，无需额外界面
- 完成任务后，进度自动更新

### 1.2 目标关联工作流

```
用户在日记中写下任务
    ↓
添加 #目标/xxx 标签关联到目标
    ↓
完成任务时（打勾）
    ↓
插件检测到任务状态变化
    ↓
自动计算关联目标进度
    ↓
更新目标进度（进度 = 已完成任务数 / 总任务数）
    ↓
刷新仪表盘显示
```

### 1.3 层级记录汇总工作流

```
日记 #noteworthy 行
    ↓
    ↓ 执行「汇总本周重点」命令
    ↓
周记（显示本周所有 #noteworthy）
    ↓
    ↓ 执行「汇总本月重点」命令
    ↓
月记（显示本月周记的 #noteworthy）
    ↓
    ↓ 执行「汇总本年重点」命令
    ↓
年记（显示本年月记的 #noteworthy）
    ↓
目标记（可筛选查看所有层级的 #noteworthy）
```

## 二、标签系统

### 2.1 支持的标签类型

| 标签 | 语法 | 示例 | 说明 |
|------|------|------|------|
| 目标关联 | `#目标/xxx` | `#目标/职业发展` | 将任务关联到目标 |
| 任务标记 | `#任务/xxx` | `#任务/项目文档` | 标记任务类型 |
| 重要标记 | `#noteworthy` | `#noteworthy` | 标记重要内容，汇总到上级 |
| 分类标记 | `#收获/xxx` | `#收获/技术` | 分类标记内容 |

### 2.2 标签解析流程

```typescript
class TagParser {
  // 解析日记中的所有标签
  parseTags(content: string): ParsedLine[] {
    const lines = content.split('\n');
    return lines.map((line, index) => ({
      lineNumber: index + 1,
      content: line,
      tags: this.extractTags(line),
      isTask: this.isTaskLine(line),
      isNoteworthy: line.includes('#noteworthy')
    }));
  }
  
  // 提取标签
  extractTags(line: string): string[] {
    const tagRegex = /#([^\s#]+)/g;
    const matches = line.match(tagRegex);
    return matches ? matches.map(tag => tag.substring(1)) : [];
  }
  
  // 判断是否为任务行
  isTaskLine(line: string): boolean {
    return /^\s*[-*]\s*\[[ x]\]/i.test(line);
  }
}
```

## 三、层级目标体系

### 3.1 目标层级

| 层级 | 名称 | 时间跨度 | 示例 |
|------|------|----------|------|
| 一级 | 🏆 人生目标 | 5-10年 | 拥有健康、平衡、有意义的人生 |
| 二级 | 📅 阶段目标 | 1-3年 | 职业发展期（2024-2026） |
| 三级 | 📆 年度目标 | 1年 | 2026年目标 |
| 四级 | ⚡ 短期目标 | 1-12周 | 本季度重点任务 |

### 3.2 目标结构示意

```
🏆 人生目标：拥有健康、平衡的人生
    │
    └── 📅 阶段目标：职业发展期
            │
            └── 📆 年度目标：2026年目标
                    │
                    ├── ⚡ 短期目标：技术提升
                    │       └── 📋 具体任务
                    │
                    └── ⚡ 短期目标：健康管理
                            └── 📋 具体任务
```

### 3.3 进度计算规则

- 目标进度 = 关联任务完成数 / 关联任务总数
- 支持手动覆盖自动计算结果
- 支持权重：子目标进度加权汇总到父目标

## 六、任务追踪流程

### 6.1 任务识别

```typescript
class TaskTracker {
  // 扫描日记中的任务
  scanTasks(content: string, filePath: string): Task[] {
    const parsed = this.tagParser.parseTags(content);
    const taskLines = parsed.filter(p => p.isTask);
    
    return taskLines.map(line => {
      const goalTag = line.tags.find(t => t.startsWith('目标/'));
      const taskTag = line.tags.find(t => t.startsWith('任务/'));
      
      return {
        id: generateId(),
        title: this.extractTaskTitle(line.content),
        status: this.extractTaskStatus(line.content),
        relatedGoalId: goalTag ? this.getGoalIdByTag(goalTag) : null,
        tags: line.tags,
        isNoteworthy: line.isNoteworthy,
        filePath,
        lineNumber: line.lineNumber,
        createdAt: new Date().toISOString(),
        completedAt: line.content.includes('[x]') ? new Date().toISOString() : null
      };
    });
  }
  
  // 任务完成时更新目标进度
  onTaskCompleted(task: Task) {
    if (task.relatedGoalId) {
      const newProgress = goalAggregator.calculateProgress(task.relatedGoalId);
      goalManager.updateProgress(task.relatedGoalId, newProgress);
    }
    
    // 刷新仪表盘
    dashboardManager.refresh();
  }
}
```

## 七、汇总命令实现

```typescript
// 命令：汇总本周重点
async function aggregateWeekCommand() {
  const weekNotePath = await getCurrentWeekNote();
  if (!weekNotePath) {
    new Notice('请先创建本周记');
    return;
  }
  
  const items = noteAggregator.aggregateDailyToWeekly(weekNotePath);
  const content = noteAggregator.generateAggregatedContent(items);
  
  // 插入到周记的指定位置
  const section = '## 📌 本周重点\n\n' + content + '\n';
  await insertIntoNote(weekNotePath, '## 📌 本周重点', section);
  
  new Notice(`已汇总 ${items.length} 条重点记录`);
}

// 命令：汇总本月重点
async function aggregateMonthCommand() {
  const monthNotePath = await getCurrentMonthNote();
  if (!monthNotePath) {
    new Notice('请先创建本月记');
    return;
  }
  
  const items = noteAggregator.aggregateWeeklyToMonthly(monthNotePath);
  const content = noteAggregator.generateAggregatedContent(items);
  
  await insertIntoNote(monthNotePath, '## 📌 本月重点', content);
  
  new Notice(`已汇总 ${items.length} 条重点记录`);
}
```
