# AI 功能需求

**版本**: v2.0.0  
**创建日期**: 2026-07-22

---

## 一、AI 功能清单

### 1.1 目标分析模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 进度分析 | 分析目标完成趋势，判断是否按计划进行 | P1 |
| 风险预警 | 识别可能延期的目标，提前预警 | P1 |
| 建议生成 | 根据分析结果提供改进建议 | P1 |
| 完成预测 | 预测目标可能完成的时间 | P2 |

### 1.2 计划生成模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 任务分解 | 根据目标自动分解为可执行的任务 | P1 |
| 周计划生成 | 根据目标和可用时间生成周计划 | P1 |
| 月计划生成 | 根据目标生成月度计划 | P1 |
| 优先级排序 | 智能排程，推荐任务执行顺序 | P1 |

### 1.3 报告生成模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 日报生成 | 根据今日记录生成日报摘要 | P2 |
| 周报生成 | 汇总本周 #noteworthy 生成周报 | P1 |
| 月报生成 | 汇总本月重点生成月报 | P1 |
| 年报生成 | 汇总年度亮点生成年报 | P2 |

### 1.4 智能标签模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 标签建议 | 根据内容建议合适的标签 | P2 |
| 任务识别 | 自动识别日记中的任务并建议标签 | P2 |
| 分类整理 | 建议将内容整理到哪个分类 | P2 |

### 1.5 对话助手模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 目标问答 | 回答关于目标进度、关联任务的问题 | P2 |
| 计划咨询 | 提供计划制定和时间管理的建议 | P2 |
| 习惯建议 | 根据数据分析提供习惯养成建议 | P2 |

## 三、隐私与安全

### 3.1 隐私保护措施

| 措施 | 说明 |
|------|------|
| 本地模型支持 | 支持 Ollama 本地部署，数据不离开设备 |
| 脱敏处理 | 发送到云端前可选择脱敏敏感信息 |
| API 密钥安全 | 密钥加密存储，不明文保存 |
| 数据最小化 | 只发送必要的上下文，不过度暴露 |

### 3.2 敏感信息处理

| 信息类型 | 处理方式 |
|----------|----------|
| 邮箱 | 替换为 [邮箱] |
| 电话号码 | 替换为 [电话] |
| 具体地址 | 替换为 [地址] |
| 身份证号 | 替换为 [证件号] |

## 四、成本控制

### 4.1 使用限制

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 每日限额 | 10000 tokens | 每日最大使用量 |
| 每月限额 | 100000 tokens | 每月最大使用量 |
| 警告阈值 | 80% | 达到阈值时提醒 |

### 4.2 使用统计

| 统计项 | 说明 |
|--------|------|
| 今日使用 | 今日已使用 tokens 数 |
| 本月使用 | 本月已使用 tokens 数 |
| 预估成本 | 根据使用量估算费用 |
| 成功率 | 请求成功率 |
