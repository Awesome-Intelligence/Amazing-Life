# 功能需求

**版本**: v1.0.0  
**创建日期**: 2026-07-22

---

## 一、项目目标

开发一款以日记为核心、界面简洁、功能全面的 Obsidian 插件，实现：

- 📝 **日记驱动** - 通过日常书写自然管理目标和任务
- 🎯 **层级目标** - 人生目标 → 阶段目标 → 年度目标 → 短期目标
- ✅ **任务关联** - 通过标签将任务关联到目标，自动追踪进度
- 📊 **层级记录** - 日记 → 周记 → 月记 → 年记 → 目标记
- ⭐ **标记汇总** - 特殊标记的内容自动汇总到上级记录
- 📈 **仪表盘** - 集中展示统计和进度信息
- 🤖 **AI 辅助** - 智能分析和计划生成（可选）

---

## 二、用户画像

**目标用户**：追求系统性管理和持续成长的知识工作者

**用户特征**：
- 习惯每日书写日记或日志
- 希望目标和任务的关联自然、不割裂
- 使用 iCloud/OneDrive/Google Drive 同步
- 已使用 Dataview/_tasks 等插件
- 期望手机端也能快速记录和查看
- 追求简洁、有逻辑的界面

## 三、功能需求

### 3.1 目标管理模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建目标 | 支持创建4级目标（人生/阶段/年度/短期） | P0 |
| 目标层级 | 支持父子目标嵌套，最多4层 | P0 |
| 进度追踪 | 关联任务完成时自动更新目标进度 | P0 |
| 目标文件 | 每个目标存储为独立 Markdown 文件 | P0 |
| 目标列表 | 按层级筛选和展示目标 | P1 |
| 里程碑 | 支持设置目标里程碑和截止日期 | P1 |
| 目标归档 | 支持归档已完成或放弃的目标 | P2 |

### 3.2 任务管理模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 任务识别 | 自动识别日记中的任务行 `- [ ]` | P0 |
| 目标关联 | 通过 `#目标/xxx` 标签关联任务到目标 | P0 |
| 任务标记 | 支持 `#任务/xxx` 标记任务类型 | P0 |
| _tasks 兼容 | 兼容 _tasks 插件的任务语法 | P1 |
| 任务统计 | 统计今日/本周/本月任务完成情况 | P1 |
| 逾期提醒 | 任务到期前提醒（可选） | P2 |

### 3.3 标签解析模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 目标标签 | `#目标/xxx` 关联任务到目标 | P0 |
| 任务标签 | `#任务/xxx` 标记任务类型 | P0 |
| 重要标记 | `#noteworthy` 标记重要内容用于汇总 | P0 |
| 分类标记 | `#分类/xxx` 支持自定义分类 | P1 |
| 标签统计 | 统计各标签使用情况 | P2 |

### 3.4 层级记录模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 日记管理 | 支持创建和管理每日日记 | P0 |
| 周记管理 | 支持创建周记（手动创建） | P0 |
| 月记管理 | 支持创建月记（手动创建） | P0 |
| 年记管理 | 支持创建年记（手动创建） | P0 |
| 目标记 | 支持创建目标记，关联特定目标 | P0 |
| 汇总功能 | 将 `#noteworthy` 内容汇总到上级记录 | P0 |

### 3.5 汇总系统

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 日记→周记 | 汇总本周日记的所有 `#noteworthy` | P0 |
| 周记→月记 | 汇总本月周记的所有 `#noteworthy` | P0 |
| 月记→年记 | 汇总本年月记的所有 `#noteworthy` | P0 |
| 全局汇总 | 目标记可筛选查看所有层级的 `#noteworthy` | P0 |
| 汇总格式 | 保留原文 + 来源链接 | P0 |

### 3.6 仪表盘模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 目标进度 | 展示各层级目标的进度 | P0 |
| 热力图 | 展示本周/本月活动热力图 | P1 |
| 任务统计 | 今日待办、本周完成、逾期任务 | P1 |
| 重要标记 | 最近的重要标记记录 | P1 |
| 刷新机制 | 支持手动刷新和自动刷新 | P1 |

### 3.7 AI 辅助模块（可选）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 目标分析 | 分析目标完成情况并提供建议 | P2 |
| 计划生成 | 根据目标自动分解任务 | P2 |
| 周报生成 | 自动生成周报/月报内容 | P2 |
| AI 设置 | 支持配置 OpenAI/Claude API | P2 |

### 3.8 设置面板

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 路径设置 | 配置日记/周记/月记/年记/目标记目录 | P0 |
| 标签设置 | 配置标记标签前缀 | P0 |
| 进度设置 | 配置是否自动计算进度 | P0 |
| 模板设置 | 配置各类笔记模板 | P1 |
| AI 设置 | 配置 AI API（可选） | P2 |

## 四、非功能需求

### 4.1 性能需求

| 指标 | 要求 |
|------|------|
| 首次加载时间 | < 2 秒 |
| 视图切换时间 | < 500ms |
| 数据更新延迟 | < 100ms |
| 内存占用 | < 100MB |
| 支持数据量 | 支持 1000+ 任务、100+ 目标、1000+ 记录 |

### 4.2 兼容性需求

- Obsidian 版本：v1.0.0+
- 移动端支持：iOS/Android Obsidian App
- 主题兼容：支持所有 Obsidian 主题
- 插件兼容：与 Dataview、_tasks、Templater 等主流插件兼容

### 4.3 数据安全需求

- 所有数据存储在用户 vault 中
- 支持 vault 备份和恢复
- API 密钥加密存储（如使用 AI 功能）
- 支持数据导出（JSON/CSV）
