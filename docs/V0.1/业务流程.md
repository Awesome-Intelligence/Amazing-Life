## 一、用户工作流

### 1.1 规划流程（仪表盘）

用户在仪表盘中创建目标和任务：

```
用户打开仪表盘
    ↓
创建目标（如"职业发展"）
    ↓
选择目标层级（人生/阶段/年度/短期）
    ↓
在目标下创建任务（如"完成项目文档"）
    ↓
设置任务截止日期、优先级
    ↓
任务自动关联到目标
```

### 1.2 追踪流程（日记）

用户在日记中追踪任务进展：

```
用户打开今日日记
    ↓
写日记，记录今天做了什么
    ↓
标记任务 #目标/职业发展 #任务/完成项目文档
    ↓
系统解析标签
    ↓
记录：该任务在今日被提及
    ↓
更新任务关联的日期列表
```

### 1.3 回顾流程（仪表盘/目标记）

用户回顾任务进展：

```
用户打开仪表盘/目标记
    ↓
选择任务"完成项目文档"
    ↓
查看任务详情
    ↓
展示：该任务在 07-15、07-18、07-22 被提及
    ↓
展示提及的原文片段
```

### 1.4 汇总流程（周记/月记/年记）

用户查看周期性汇总：

```
用户打开月记
    ↓
执行命令"汇总本月周记"
    ↓
系统扫描本月各周记
    ↓
提取周记中的 #noteworthy 内容
    ↓
展示：本月各周的重点记录
```

## 二、标签系统

### 2.1 标签类型

| 标签 | 语法 | 用途 |
|------|------|------|
| 目标关联 | `#目标/xxx` | 将内容关联到目标 |
| 任务关联 | `#任务/xxx` | 将内容关联到任务 |
| 重要标记 | `#noteworthy` | 标记重要内容，用于汇总 |
| 分类标记 | `#分类/xxx` | 自定义分类 |

### 2.2 标签解析规则

```
日记文本
    ↓
扫描每一行
    ↓
识别任务行（- [ ]）
    ↓
提取所有标签（#开头）
    ↓
建立关联关系
    ↓
记录提及关系
```

### 2.3 标签使用示例

```markdown
# 2026-07-22

## 今日任务
- [x] 完成项目文档第一章 #目标/职业发展 #任务/完成项目文档

## 今日进展
今天完成了项目文档的前两章，感觉进展顺利 #目标/职业发展 #任务/完成项目文档 #noteworthy

## 明日计划
- [ ] 继续完善文档 #目标/职业发展 #任务/完成项目文档
```

## 三、数据关联

### 3.1 关联关系

```
目标（层级结构）
    └── 任务（关联到目标）
            └── 标签（#目标/xxx #任务/xxx）
                    └── 提及记录（日期 → 任务）
```

### 3.2 关联查询

| 查询 | 描述 |
|------|------|
| 目标 → 任务 | 从目标查询关联的所有任务 |
| 任务 → 目标 | 从任务查询关联的目标 |
| 任务 → 日期 | 从任务查询被提及的所有日期 |
| 日期 → 任务 | 从日期查询被提及的任务 |
| 目标 → 提及 | 从目标查询所有任务的提及记录 |

## 四、层级目标

### 4.1 目标层级

| 层级 | 名称 | 时间跨度 | 示例 |
|------|------|----------|------|
| 1 | 人生目标 | 5-10年 | 拥有健康、平衡的人生 |
| 2 | 阶段目标 | 1-3年 | 职业发展期 |
| 3 | 年度目标 | 1年 | 2026年目标 |
| 4 | 短期目标 | 1-12周 | 本季度重点 |

### 4.2 目标结构

```
🏆 人生目标
    └── 📅 阶段目标
            └── 📆 年度目标
                    └── ⚡ 短期目标
```

### 4.3 进度计算

- 目标进度 = 关联任务的完成数 / 关联任务总数
- 支持手动覆盖自动计算
- 支持权重：子目标进度加权汇总到父目标

## 五、层级记录

### 5.1 记录层级

| 层级 | 名称 | 周期 | 汇总内容 |
|------|------|------|----------|
| 1 | 日记 | 每日 | #noteworthy 标记行 |
| 2 | 周记 | 每周 | 日记的 #noteworthy |
| 3 | 月记 | 每月 | 周记的 #noteworthy |
| 4 | 年记 | 每年 | 月记的 #noteworthy |
| 5 | 目标记 | 持续 | 该目标的所有 #noteworthy |

### 5.2 汇总流程

```
日记 #noteworthy
    ↓ 汇总命令
周记（本周 #noteworthy）
    ↓ 汇总命令
月记（本月周记的 #noteworthy）
    ↓ 汇总命令
年记（本年月记的 #noteworthy）
```

### 5.3 汇总格式

汇总保留原文和来源链接：

```markdown
> [!source] 07-22
> 今天完成了项目文档的前两章
> — 来自：[[2026-07-22]]
```
