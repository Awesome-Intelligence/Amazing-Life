---

## 二、设计原则

1. **Markdown 优先**: 所有数据以 .md 文件存储，用户可直接阅读和编辑
2. **元数据标识**: 使用 `A-` 前缀标识插件数据，避免与其他插件冲突
3. **Dataview 查询**: 提及记录等数据通过 Dataview 实时查询，不单独存储
4. **独立文件**: 每个目标、任务都是独立的 .md 文件
5. **目录可配置**: 所有目录路径可在设置中修改

### 3.2 目标模型 (Goal)

**frontmatter 字段**:

| 字段 | 说明 | 示例 |
|------|------|------|
| `A-id` | 唯一标识 | `goal-001` |
| `A-type` | 类型固定为 `goal` | `goal` |
| `A-title` | 标题 | `职业发展` |
| `A-level` | 层级 (1-4) | `2` |
| `A-parent` | 父目标 ID | `goal-001` |
| `A-status` | 状态 | `active` |
| `A-progress` | 进度百分比 | `50` |
| `A-weight` | 权重 | `0.8` |
| `A-start` | 开始日期 | `2024-01-01` |
| `A-due` | 截止日期 | `2026-12-31` |
| `A-created` | 创建时间 | `2024-01-01` |
| `A-updated` | 更新时间 | `2026-07-22` |

**层级定义**:

| level | 类型 | 说明 |
|-------|------|------|
| 1 | 人生目标 | 一生的终极追求 |
| 2 | 阶段目标 | 3-5年阶段目标 |
| 3 | 年度目标 | 年度计划 |
| 4 | 短期目标 | 季度/月度目标 |

**状态定义**:

| status | 说明 |
|--------|------|
| `active` | 进行中 |
| `completed` | 已完成 |
| `abandoned` | 已放弃 |

### 3.3 任务模型 (Task)

**frontmatter 字段**:

| 字段 | 说明 | 示例 |
|------|------|------|
| `A-id` | 唯一标识 | `task-001` |
| `A-type` | 类型固定为 `task` | `task` |
| `A-title` | 标题 | `完成项目文档` |
| `A-status` | 状态 | `in-progress` |
| `A-priority` | 优先级 (1-5) | `2` |
| `A-due` | 截止日期 | `2026-07-25` |
| `A-goal` | 关联目标 ID | `goal-002` |
| `A-tags` | 标签列表 | `["职业发展"]` |
| `A-source` | 来源文件 | `Daily/2026-07-22.md` |
| `A-created` | 创建时间 | `2026-07-22` |
| `A-completed` | 完成时间 | `null` |

**状态定义**:

| status | 说明 |
|--------|------|
| `pending` | 待办 |
| `in-progress` | 进行中 |
| `completed` | 已完成 |
| `cancelled` | 已取消 |

**优先级定义**:

| priority | 说明 |
|----------|------|
| 1 | 最高 |
| 2 | 高 |
| 3 | 中 |
| 4 | 低 |
| 5 | 最低 |
