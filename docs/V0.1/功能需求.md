# 功能需求

**版本**: v1.0.0
**创建日期**: 2026-07-22
**更新日期**: 2026-07-22

---

## 一、项目目标

帮助用户通过"规划-追踪-回顾"的循环，系统性地管理生活和目标。

---

## 二、设计原则

1. **Markdown 优先**: 所有数据以 .md 文件存储，用户可直接阅读和编辑
2. **元数据标识**: 使用 `A-` 前缀标识插件数据，避免与其他插件冲突
3. **Dataview 查询**: 提及记录等数据通过 Dataview 实时查询，不单独存储
4. **独立文件**: 每个目标、任务都是独立的 .md 文件
5. **目录可配置**: 所有目录路径可在设置中修改

---

## 三、用户工作流

### 3.1 规划阶段（仪表盘）

用户在仪表盘中完成目标的创建和拆解：

```
仪表盘
  └── 创建目标（4级层级：人生/阶段/年度/短期）
          └── 在目标下创建任务
                  └── 设置截止日期、优先级
```

**典型操作**：
1. 用户打开仪表盘
2. 创建"职业发展"目标（阶段目标，level: 2）
3. 在目标下创建"完成项目文档"、"准备晋升材料"等任务
4. 设置任务截止日期

### 3.2 追踪阶段（日记）

用户在日常日记中追踪任务进展：

```
日记
  └── 写日记时标记
          └── #目标/职业发展 #任务/完成项目文档 #noteworthy
```

**典型操作**：
1. 用户打开今日日记
2. 写"今天完成了项目文档的前两章"
3. 标记 `#目标/职业发展 #任务/完成项目文档`
4. 如有重要内容，标记 `#noteworthy`

### 3.3 回顾阶段（仪表盘/目标详情）

用户回顾目标进展，查看提及历史：

```
仪表盘/目标详情
  └── 查看目标详情
          └── Dataview 查询：该目标在日记中被提及的日期
                  └── 获得"持续努力"的感知
```

**典型操作**：
1. 用户打开仪表盘
2. 查看"职业发展"目标详情
3. 页面展示 Dataview 查询结果：07-15、07-18、07-22 被提及

### 3.4 汇总阶段（阶段性记录/周记/月记/年记）

用户在阶段性记录/周记/月记/年记中查看汇总：

```
阶段性记录
  └── 汇总期间内的 #noteworthy 记录
          └── 查看本阶段的重要内容和进展
```

**典型操作**：
1. 用户打开季度总结（Phases/Q1-2026.md）
2. 页面展示 Dataview 查询结果：本季度所有 #noteworthy 记录
3. 查看本阶段目标进度变化

## 四、功能需求

### 4.1 仪表盘模块

仪表盘是用户的"指挥中心"，支持规划和回顾。

#### 4.1.1 目标管理

- **创建目标**: 在仪表盘中创建目标，支持4级层级（1=人生/2=阶段/3=年度/4=短期）
- **编辑目标**: 修改目标名称、描述、截止日期
- **删除目标**: 删除目标及其关联关系
- **归档目标**: 归档已完成或放弃的目标
- **目标树**: 按层级展示目标树状结构

#### 4.1.2 任务管理

- **创建任务**: 在目标下创建任务
- **编辑任务**: 修改任务名称、截止日期、优先级
- **删除任务**: 删除任务
- **任务详情**: 查看任务详情，包括通过 Dataview 查询的提及历史

#### 4.1.3 进度展示

- **目标进度**: 展示各层级目标的进度（自动计算）
- **任务状态**: 展示任务状态（pending/in-progress/completed/cancelled）
- **热力图**: 展示本周/本月活动热力图
- **任务统计**: 今日待办、本周完成、逾期任务数量

#### 4.1.4 回顾能力

- **提及历史**: 通过 Dataview 查询展示目标/任务在日记中被提及的日期
- **目标进展时间线**: 展示目标关联任务的完成时间线
- **持续努力感知**: 可视化显示"某目标连续多天被提及"

### 4.2 日记模块

日记是用户的"追踪中心"，记录日常进展。

#### 4.2.1 日记编写

- **日记模板**: 提供日记模板，包含任务区、记录区
- **自动识别**: 自动识别日记中的任务行（`- [ ]`）
- **标签解析**: 解析日记中的 `#目标/xxx`、`#任务/xxx`、`#noteworthy`

#### 4.2.2 标签关联

- **目标标签**: `#目标/xxx` 将当前行关联到目标
- **任务标签**: `#任务/xxx` 将当前行关联到任务
- **重要标记**: `#noteworthy` 标记重要内容，用于汇总
- **分类标记**: `#分类/xxx` 支持自定义分类

### 4.3 层级记录模块

层级记录用于周期性回顾。

#### 4.3.1 记录类型

| 类型 | 频率 | 用途 |
|------|------|------|
| 日记 (Daily) | 每日 | 日常记录、任务标记 |
| 周记 (Weekly) | 每周 | 本周总结、#noteworthy 汇总 |
| 月记 (Monthly) | 每月 | 月度回顾、进度分析 |
| 年记 (Yearly) | 每年 | 年度总结、成就回顾 |
| 阶段性记录 (Phases) | 手动 | 季度/阶段复盘、里程碑记录 |

#### 4.3.2 汇总功能

- **汇总方式**: 用户在笔记中嵌入 Dataview 查询语句
- **汇总内容**: 汇总期间的 #noteworthy 标记内容
- **汇总格式**: 保留原文 + 来源链接（日期）
- **手动触发**: 用户自行刷新 Dataview 查询结果

### 4.4 视图展示模块

支持多种视图展示方式。

#### 4.4.1 视图类型

- **列表视图**: 以列表形式展示，支持排序和筛选
- **看板视图**: 以看板形式展示，支持按状态/标签/目标分组
- **画廊视图**: 以卡片网格形式展示
- **日历视图**: 以日历形式展示，按日期组织
- **时间线视图**: 以时间线形式展示目标和里程碑
- **仪表盘视图**: 集中展示统计和进度信息

#### 4.4.2 视图操作

- **视图切换**: 支持快速切换视图
- **视图偏好**: 记住用户偏好的视图设置
- **刷新机制**: 支持手动和自动刷新

### 4.5 标签解析模块

解析日记中的标签，建立关联。

#### 4.5.1 标签类型

| 标签 | 语法 | 用途 |
|------|------|------|
| 目标关联 | `#目标/xxx` | 将内容关联到目标 |
| 任务关联 | `#任务/xxx` | 将内容关联到任务 |
| 重要标记 | `#noteworthy` | 标记重要内容，用于汇总 |
| 分类标记 | `#分类/xxx` | 自定义分类 |

#### 4.5.2 解析规则

- 自动识别任务行（`- [ ]`）
- 提取行中所有标签
- 通过 `A-goal` 字段建立"任务-目标"关联关系
- 提及历史通过 Dataview 实时查询，不单独存储

### 4.6 设置面板

#### 4.6.1 目录设置

- 插件数据目录（默认: Amazing Life）
- 日记目录（默认: Daily）
- 周记目录（默认: Weekly）
- 月记目录（默认: Monthly）
- 年记目录（默认: Yearly）
- 阶段性记录目录（默认: Phases）

#### 4.6.2 标签设置

- 目标标签前缀（默认: 目标）
- 任务标签前缀（默认: 任务）
- 重要标记标签（默认: noteworthy）

#### 4.6.3 其他设置

- 自动更新进度（默认: 开启）
- 默认视图模式

## 五、数据存储

### 5.1 文件结构

```
vault/
├── Daily/                          # 日记目录（可配置）
├── Weekly/                         # 周记目录（可配置）
├── Monthly/                        # 月记目录（可配置）
├── Yearly/                         # 年记目录（可配置）
├── Phases/                         # 阶段性记录目录（可配置）
│
├── Amazing Life/                   # 插件数据目录（可配置）
│   ├── goals/                     # 目标目录
│   │   ├── _index.md             # 目标索引
│   │   ├── goal-001.md           # 目标文件
│   │   └── goal-002.md
│   ├── tasks/                      # 任务目录
│   │   ├── _index.md             # 任务索引
│   │   ├── task-001.md           # 任务文件
│   │   └── task-002.md
│   └── config.json                 # 插件配置
└── ...
```

### 5.2 元数据标识

| 前缀 | 用途 |
|------|------|
| `A-` | Amazing Life 插件数据标识 |

### 5.3 目标层级

| level | 类型 | 说明 |
|-------|------|------|
| 1 | 人生目标 | 一生的终极追求 |
| 2 | 阶段目标 | 3-5年阶段目标 |
| 3 | 年度目标 | 年度计划 |
| 4 | 短期目标 | 季度/月度目标 |

## 六、非功能需求

### 6.1 性能需求

| 指标 | 要求 |
|------|------|
| 首次加载时间 | < 2 秒 |
| 视图切换时间 | < 500ms |
| 标签解析延迟 | < 100ms |
| 内存占用 | < 100MB |

### 6.2 兼容性需求

- Obsidian 版本：v1.0.0+
- 移动端：iOS/Android Obsidian App
- 主题兼容：跟随 Obsidian 主题
- 依赖插件：Dataview（用于实时查询）
- 插件兼容：与 _tasks、Templater 兼容

### 6.3 数据安全

- 数据存储在用户 vault 的 Markdown 文件中
- 支持 vault 备份和恢复
- 插件配置存储在 config.json

## 七、核心查询

### 7.1 Dataview 查询示例

**查询所有目标**:
```dataview
TABLE A-title, A-level, A-status, A-progress
FROM "Amazing Life/goals"
WHERE A-type = "goal"
SORT A-level ASC
```

**查询目标下的任务**:
```dataview
TABLE A-title, A-status, A-priority, A-due
FROM "Amazing Life/tasks"
WHERE A-type = "task"
WHERE A-goal = "goal-002"
SORT A-priority ASC
```

**查询目标提及记录**:
```dataview
TABLE date, substring(source.ctext, 0, 100) as 内容
FROM "Daily"
WHERE contains(source.ctext, "#目标/职业发展")
SORT date DESC
```

**查询 #noteworthy 记录**:
```dataview
TABLE date, substring(source.ctext, 0, 150) as 内容
FROM "Daily"
WHERE contains(source.ctext, "#noteworthy")
SORT date DESC
LIMIT 20
```
