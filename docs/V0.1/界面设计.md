## 三、笔记模板

### 3.1 日记模板

**设计原则**：日记保持纯净，不自动插入统计信息块。用户自由书写，通过标签完成关联。

```markdown
# 2026年7月22日 周二

## 今日记录

在这里写下今天的想法、经历和收获...

- 完成重要任务 #目标/xxx #任务/xxx
- 有新的想法或收获 #noteworthy

## 今日任务
- [ ] 任务1
- [ ] 任务2

## 明日计划
- [ ] 计划任务

---

*由 Amazing Life 管理*
```

## 四、主题适配

### 4.1 CSS 变量定义

插件使用 CSS 变量实现主题兼容，自动跟随 Obsidian 当前主题：

```css
/* CSS 变量 - 跟随 Obsidian 主题 */
:root {
  /* 背景色 */
  --lm-bg-primary: var(--background-primary);
  --lm-bg-secondary: var(--background-secondary);
  --lm-bg-tertiary: var(--background-tertiary);
  
  /* 文字色 */
  --lm-text-primary: var(--text-primary);
  --lm-text-secondary: var(--text-secondary);
  --lm-text-muted: var(--text-muted);
  
  /* 强调色 */
  --lm-accent-primary: var(--interactive-accent);
  --lm-accent-success: #4ade80;
  --lm-accent-warning: #fbbf24;
  --lm-accent-danger: #ef4444;
  
  /* 边框 */
  --lm-border-color: var(--background-modifier-border);
  
  /* 圆角 */
  --lm-radius-sm: 4px;
  --lm-radius-md: 8px;
  --lm-radius-lg: 12px;
}
```

### 4.2 组件样式

```css
/* 卡片组件 */
.lm-card {
  background: var(--lm-bg-secondary);
  border: 1px solid var(--lm-border-color);
  border-radius: var(--lm-radius-md);
  padding: 16px;
}

/* 按钮组件 */
.lm-button {
  background: var(--lm-accent-primary);
  color: var(--lm-text-primary);
  border-radius: var(--lm-radius-sm);
  padding: 8px 16px;
  cursor: pointer;
}

.lm-button:hover {
  opacity: 0.9;
}

/* 进度条组件 */
.lm-progress {
  background: var(--lm-bg-tertiary);
  border-radius: var(--lm-radius-sm);
  height: 8px;
  overflow: hidden;
}

.lm-progress-bar {
  background: var(--lm-accent-primary);
  height: 100%;
  transition: width 0.3s ease;
}

/* 热力图组件 */
.lm-heatmap-cell {
  width: 12px;

  border-radius: 2px;
}

.lm-heatmap-level-0 { background: var(--lm-bg-tertiary); }

.lm-heatmap-level-2 { background: #40c463; }
.lm-heatmap-level-3 { background: #30a14e; }
.lm-heatmap-level-4 { background: #216e39; }
```
