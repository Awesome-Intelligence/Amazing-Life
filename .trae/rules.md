# Trae 项目规则

## 项目背景

- **项目名称**: Life Manager
- **项目类型**: Obsidian 插件
- **当前阶段**: 需求规划中，尚未开始开发
- **核心理念**: 以日记为核心，通过标签自然关联目标和任务

---

## 开发优先级

1. **V1 核心功能优先** - 完成后再考虑 V2
2. **日记纯净性优先** - 不自动插入统计信息到日记
3. **Markdown 原生优先** - 数据存储在用户 vault 的 Markdown 文件中
4. **插件兼容优先** - 与 Dataview、_tasks 等插件兼容
